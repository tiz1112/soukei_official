# 株式会社 創敬 サイト(soukeibros.jp)

特別な道具を使わない、HTML と CSS だけのサイトです。フォルダの中身をそのままサーバーに置けば動きます。

## ファイルの構成

| ファイル | 役割 |
|---|---|
| `index.html` | トップページ |
| `thanks.html` | 申し込み完了ページ |
| `company.html` | 会社概要 |
| `privacy.html` | 個人情報の取り扱い(下書き。公開前に内容を確認すること) |
| `contact.php` | 申し込みフォームの送信処理(メールで通知) |
| `css/style.css` | 全ページ共通の見た目。色と書体は冒頭の `:root` で管理 |
| `assets/` | ロゴ、アイコン、共有用画像、写真 |

## 公開前にやること

1. **`contact.php` の設定**:冒頭の `MAIL_TO` に、申し込みを受け取るメールアドレスを入れる。`MAIL_FROM` は soukeibros.jp のアドレスにする。
2. **空欄を埋める**:各 HTML の中で `TODO` を検索すると、未記入の場所がすべて出てくる。画面上では `[ ]` で囲んだ文字が未記入の印。
3. **写真を入れる**:`assets/` に写真を置き、`index.html` の「写真A1」「写真A3」「写真A4」のコメントに書いてある `<img>` に差し替える。
4. **個人情報の取り扱い**:実際の運用と合っているか確認する。
5. **送信テスト**:公開先で実際にフォームを送り、メールが届くこと、完了ページに進むことを確かめる。

## サーバーの条件

- PHP が動くこと(`contact.php` がメール送信に `mb_send_mail` を使う)。
- `https://` で公開すること。

## 更新するときの決まり

- 色、書体、余白は `css/style.css` の `:root` の値を変える。個別の場所に直接書かない。
- 見出しの中の `<span class="ph">…</span>` は、文節の途中で改行させないための囲み。見出しを書き換えるときは、意味の切れ目ごとに囲む。
- ヘッダーとフッターは4つの HTML に同じものが入っている。変えるときは4つとも変える。
- 紺色(`--accent`)は申し込みボタンと細い線だけに使う。
